VISUAL STYLE:

Create a sophisticated, clean and premium design. The website should feel trustworthy, warm, feminine, professional and calm.

Use this color palette:

- Soft terracotta / burnt orange

- Muted teal

- Deep olive green

- Warm beige / sand

- Off-white background

- Dark charcoal text

Use elegant serif typography for main headings and a clean modern sans-serif font for body text.

Do not make the website look crowded, cheap or overly colorful. Use generous white space, soft shadows, rounded service cards, subtle transitions and elegant section dividers.
